# WOW SCHOOL · Unit 1A v4

Исправленная версия для Holst.

## Главное
- Фиксированный внутренний холст 1600×900 и автоматический scale-to-fit: элементы не наезжают друг на друга при изменении размера iframe.
- Полностью переработанный логотип WOW SCHOOL.
- 6 блоков + результаты.
- Только Lesson 1A.
- Browser speechSynthesis не используется.
- Аудио-кнопка включается только если соответствующий MP3 реально существует.

## Нужные MP3
Положите в `assets/audio/`:
- phrases_1.mp3
- numbers_1.mp3
- days_1.mp3
- pronunciation_1.mp3
- listening_1.mp3
- listening_2.mp3

Без этих файлов интерфейс честно показывает `Нужен реальный британский MP3`, а не пытается использовать роботизированный TTS.
