# WOW SCHOOL · English File Beginner · Unit 2B — That’s my bus!

Полный интерактивный review-module на базе универсального WOW SCHOOL шаблона.

## Что внутри
- Preview screen — модуль всегда стартует с обложки.
- 7 учебных блоков + Results.
- Words & Phrases — 10 заданий.
- Grammar — 10 заданий по Wh- / How questions with `be`.
- Number Detective — 10 аудиозаданий 11–100 с акцентом на teen / ty.
- Phone & Personal Info — 8 заданий.
- Reading — новый текст + 5 вопросов.
- Question Sort — 9 перемешиваемых карточек по 3 колонкам.
- Listening Mission — 2 новых мини-диалога + 8 вопросов.

## Аудио
Сохранена аудиомеханика исходного шаблона. Для устойчивого воспроизведения:
- отдельные слова / числа отправляются как отдельные короткие запросы;
- Reading заранее разделён на короткие предложения;
- Listening проигрывается по репликам;
- длинный телефонный номер дополнительно разбит на 3 маленьких аудиофрагмента.

## Визуалы
На этом этапе модуль собран с нейтральными встроенными UI-визуалами и уже существующим универсальным изображением для Listening. Отдельные реалистичные картинки для Unit 2B будут добавлены на следующем этапе без изменения логики заданий.

## Holst
Формат 16:9, без внутренних скроллов, рассчитан на iframe. Код — в `iframe.txt`.
