# WOW SCHOOL · English File Beginner · Lesson 1A · v5

Полностью переработанная версия для Holst.

## Что исправлено
- Никаких native `<select>`: фраза всегда видна рядом с вариантами ответа.
- Один вопрос на экране внутри каждого блока — текст не накладывается.
- Ошибка не блокирует задание: ученик может попробовать ещё раз.
- Результат считает ответы, выполненные правильно с первой попытки.
- Pronunciation поддерживает drag & drop и click-to-place; неверное слово не переносится в неправильный блок.
- Добавлен новый Reading Café блок с коротким текстом и comprehension.
- Добавлены встроенные CSS/SVG-подобные иллюстрации для кафе, грамматики, чисел, календаря, чтения и listening.
- Аудио больше не требует локальных MP3: используется live British-English cloud TTS. Сначала пробуется StreamElements UK voices Brian/Amy, затем Google en-GB. Browser speechSynthesis не используется.
