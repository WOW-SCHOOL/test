# WOW SCHOOL · English File Beginner · Lesson 1A Review

Interactive 16:9 self-check module for Holst / iframe embedding.

## Source lock
Content is limited to Lesson 1A **A cappuccino, please**:
- verb **be** with **I / you**
- numbers 0–10
- pronunciation /h/, /aɪ/, /iː/
- days of the week
- introductions, café phrases, saying goodbye

No 1B countries, nationalities, he/she/it, or unrelated A1 vocabulary are used in the student tasks.

## Screens
1. Start / overview
2. Words & Phrases — 12 matching items
3. Grammar — 12 questions
4. Numbers 0–10 — 8 audio rounds + 4 sequences
5. Days & Goodbye — 7-item ordering + 5 quick questions
6. Pronunciation — 12-word sound sort
7. Listening Mission — 8 comprehension questions
8. Final results with per-skill breakdown and review mode

## Audio
The app automatically selects the best British English voice available through the browser's Web Speech API. It prioritises high-quality UK voices if installed by the OS/browser. This makes the package self-contained and immediately usable.

For guaranteed identical *human-recorded* audio on every device, replace the fallback with licensed MP3 recordings in `assets/audio/`. See `assets/audio/README.md`.

## Run locally
```bash
python3 -m http.server 8000
```
Open `http://localhost:8000`.

## GitHub Pages
Upload this folder to a repository. Enable GitHub Pages for the branch/folder containing `index.html`.

## Holst
Use the iframe from `HOLST_IFRAME_CODE.txt`, replacing the placeholder URL with your GitHub Pages URL.
