# Audio files

The app checks for these MP3 files first and automatically falls back to the best available British `en-GB` browser voice if a file is missing.

Recommended human-recorded files:
- `listening_mission.mp3`
- `goodbye_friday.mp3`
- `number_0.mp3` ... `number_10.mp3`
- `word_house.mp3`, `word_hi.mp3`, `word_hello.mp3`, `word_helen.mp3`
- `word_im.mp3`, `word_nice.mp3`, `word_five.mp3`, `word_nine.mp3`
- `word_meet.mp3`, `word_three.mp3`, `word_tea.mp3`, `word_please.mp3`

For your final production version, record these with a natural British speaker or a licensed high-quality British voice. No code change is required: just place the MP3 files in this folder with the exact names above.
