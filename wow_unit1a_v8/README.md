WOW SCHOOL · English File Beginner · Unit 1A · V8

V8 is based on the original V5. Visual design and learning tasks are unchanged.
Only the online-audio transport was reworked for Holst iframe compatibility.

Audio changes:
- Google UK TTS remains the primary voice (same family as V5).
- document-level and media-level referrer policy = no-referrer;
- one persistent audio element is reused;
- no crossOrigin attribute is set;
- dialogues are requested as one continuous audio item;
- long reading text is split into safe chunks;
- two Google URL variants plus translate.googleapis.com fallback are tried.
