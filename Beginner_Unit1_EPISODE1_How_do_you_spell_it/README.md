# WOW SCHOOL · English File Beginner · Unit 1 · Practical English Episode 1

## How do you spell it?

Interactive review module based on the supplied English File lesson materials and the WOW SCHOOL universal template.

### Learning focus
- The alphabet and spelling names/words
- Classroom vocabulary and classroom language
- `verb be` review with I / he / she / it
- Checking into a hotel
- Booking a table
- Useful phrases such as `How do you spell it?`, `Sorry?`, `How can I help you?`, `I have a reservation.`
- Alphabet sound groups `/iː/`, `/e/`, `/eɪ/`

### Structure
1. Words & Phrases — 10 questions
2. Grammar Check — 10 questions
3. Spelling Challenge — 10 questions
4. Real-life English — 8 questions
5. Reading Mission — 6 questions
6. Alphabet Sound Sort — 12 draggable cards, shuffled on each new run
7. Listening Mission — 2 new dialogues / 8 questions
8. Results screen

### Technical notes
- 1600×900 / 16:9 base layout
- Starts from Preview screen
- No internal scrolling intended
- Images are stored locally in `assets/images/`
- Online TTS audio uses the same mechanism as the universal WOW SCHOOL template
- Block 6 order is randomized and preserved during the current attempt
- `object-fit: contain` is used for instructional visuals to avoid clipping important content

### Image generation note
The lesson package includes finished local image assets. A dedicated external image-generation connection was unavailable during final assembly, so the module uses generated visual crops from the current creation session plus the existing high-quality WOW template scene assets; there are no placeholders that require manual replacement.
