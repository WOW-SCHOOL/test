GRAMMAR SWITCHBOARD v2 — SEPARATE FOLDER VERSION

This version is designed to live in the SAME GitHub repository as your other exercises,
but inside its own folder.

Repository structure:
test/
  grammar-switchboard-v2/
    index.html
    preview.png
    oembed.json
    HOLST_IFRAME_CODE.txt
    HOLST_URL.txt

UPLOAD:
1. Open the existing repository WOW-SCHOOL/test.
2. Create a NEW folder: grammar-switchboard-v2
3. Upload ALL files from this folder into it.
4. Wait for GitHub Pages to redeploy.
5. In Holst create a NEW iframe object using:
   https://wow-school.github.io/test/grammar-switchboard-v2/?v=2

WHY A SEPARATE FOLDER:
- no conflict with the old root Grammar Switchboard;
- no merge conflict with Sound Lockers;
- independent preview/oEmbed metadata;
- each exercise gets its own permanent URL;
- easier to keep dozens of exercises in one repository.

The exercise logic/design itself has been preserved:
- 15 questions
- A/B switch controls
- Check answers
- Reset
- score
- Holst auto-fit/no internal scrolling
- preview via oEmbed
